# 01. User interface

The layout is the command bar of the Windows 11 apps over the navigation row and the split view. Below
1100 px of width the labels of the command bar go and its commands move, as icons, to the end of the
navigation row; the rules of the selected group show their switches at the end of their rows; the search
field grows into the free width of the navigation row. The chrome (the tab row, the command bar, the
navigation row, the message bar, the status bar, the settings tab and the editor of a theme) is drawn by
W# from what WinWeaver gives it (`docs/ww.md` of supakov/ww); the window itself is the reference of the look, and the
screenshots of CI show it (`AGENTS.md` section 6).

## 1. One window, documents as tabs

- The program has one window. Its content is a row of tabs; every tab is a document or a function.
- Document tabs: a profile (`.wwprofile`), a diff (`.wwdiff`), a catalog (an import of policy templates,
  or a `.wwcatalog` or `.admx` file opened without importing it), the editor of a catalog, a registry file
  (`.reg`), a users file (`.wwusers`), a Markdown page (the guide, the licence, the reference, any `.md`
  file) and the editor of a theme (`.wwtheme`). A tab shows its icon, its title, a dot when it has unsaved
  changes and a close button; the tip shows the full path of its file.
- Tabs of one kind that exist at most once: the bookmarks, the registry, MCP and Settings; opening one again
  brings it to the front.
- A tab is closed with its close button, the middle mouse button or `Ctrl+W`; a tab with unsaved changes
  asks first: Save, Don't save or Cancel. `Ctrl+Tab` and `Ctrl+Shift+Tab` cycle the tabs.
- A tab is moved by dragging it along the row (a line shows where it goes), with `Ctrl+Shift+PgUp` and
  `Ctrl+Shift+PgDn`, or with the menu of its right button (move left, move right, close). The tab in
  front stays in front, and the restored session keeps the order.
- The menu button sits at the left end of the tab row; a "+" button after the last tab makes a new empty
  profile (`Ctrl+N`).
- The window remembers the tabs with files and the active one, and opens them again at the next start (a
  setting); the drafts of unsaved documents come back too (`02-documents.md` section 8). The status bar says
  how many drafts were restored and how many files of the last session are missing.
- A file dropped on the window opens in a tab by its extension. With no tab open the window says how to
  start (Menu, New or `Ctrl+N`).

## 2. Command bar

- A command bar in the style of Windows 11 apps under the tab row: icons in colour above short labels,
  grouped by separators. The commands depend on the active tab:
  - profile: New, Open, Save; Check, Build; This PC (a menu), Compare (a menu); Catalogs (a menu);
  - diff: Open, Save, Save as; Apply (every difference to the base profile);
  - catalog of an import: Open; Show in the profile, Export, Compare (a menu), Edit;
  - catalog of a file: Open; Import, Compare (a menu), Edit;
  - editor of a catalog: Save;
  - registry: Refresh; New key, New value, Edit, Delete; Bookmark, Find, Permissions;
  - registry file: Open, Save, Save as; New key, New value, Edit, Delete; Open in the registry;
  - users file: Save, Save as; Add, Duplicate, Remove, Up, Down; Unlock, or Lock, Password and Master
    password while the passwords are unlocked; Check, Read this PC, Create on this PC, Apply passwords,
    Script;
  - bookmarks, Markdown page: Open;
  - MCP: Start, Stop;
  - editor of a theme: Open, Save, Save as;
  - Settings: no commands.
- The menu This PC of a profile: read this PC into a new profile, read the selection into this profile,
  check the selection on this PC; save an apply script, a return-to-defaults script, a registry file, a
  return-to-defaults registry file or an audit script for the selection; apply the selection to this PC,
  return it to the Windows defaults, undo a change from its backup; open an audit report.
- The menu Compare of a profile: with a file, with each preset, with its unsaved changes. The menu Compare
  of a catalog: the other loaded imports and the open catalog files.
- The menu Catalogs: every catalog file of `imports/`, read again each time the menu opens (a loaded one
  with a check mark and its text in the accent colour opens its catalog tab; one not loaded loads at a
  click and opens its tab), Import the templates of this Windows, Import a folder, Import a catalog file,
  Import an archive, New catalog, and the settings of the policy templates.
- A command with a key shows it in its tip.

## 3. Navigation row: history, breadcrumb, star

- The navigation row appears for a profile and a catalog tab. It holds the Back and Forward arrows (a
  profile), the breadcrumb of the selection, the bookmark star and the search (section 4). The other tabs
  keep their search at the right end of the command bar.
- The breadcrumb shows the path of the selected item: the groups above it and the item. Every part is a
  button that selects that group; the crumb of a rule keeps the group it is shown in. A narrow row
  shortens the breadcrumb to its first and last parts with a menu of the others.
- Back and Forward (`Alt+Left`, `Alt+Right`) move through the selections of the profile tab.
- The star (`Ctrl+B`) marks the selected option of a profile, a catalog or a diff as a bookmark (section
  9) or takes the mark off; it is filled when the option is bookmarked.

## 4. Search

- A profile, a catalog, a diff, a Markdown page, the bookmarks, the MCP tab, a registry file and a users
  file have their own search: the profile tree, the policies of a catalog tab, the differences, the
  blocks of a page, the bookmarks, the MCP journal, the keys, values and comments of a registry file, the
  accounts. The registry tab has Find instead (section 15); Settings and the editors of a theme and of a
  catalog have no search.
- The search is an icon; a click or `Ctrl+F` opens it into a field. The close button or `Esc` clears and
  closes it. Clearing a search opens the groups above the selection and scrolls it into view.
- The search filters as the text is typed: in a tree the matching items and their groups stay, the rest is
  hidden. Matching ignores case, and several words match in any order. In the profile tree a rule matches
  by its id, its title, its summary and its tags, in English and in the language of the interface.
- `Enter` remembers the text; a menu beside the field lists the last 20 searches (kept in the settings).

## 5. Menu

The menu button (three lines) sits at the left end of the tab row. Its menu:

- New: an empty profile (`Ctrl+N`), a profile from each preset (Office, Strict, Laptop, Home), an empty
  users file, a users file of the accounts of this PC.
- Open... (`Ctrl+O`, every kind of file the program opens), Open recent (10 files), Save (`Ctrl+S`),
  Save as... (`Ctrl+Shift+S`), Close tab (`Ctrl+W`).
- Guide (`F1`), License, Bookmarks, Registry, MCP server, Settings (`Ctrl+,`).
- About (a window over the tabs: the version with its commit, the settings file, what the window draws
  with), Exit.

## 6. Profile view

The profile tab is a split view: the tree on the left, the detail panel on the right, a draggable splitter.

### 6.1 Tree

- Three roots by mechanism: Installation (the answer file and its scripts), Policies (every rule that only
  writes the registry, with every loaded import of policy templates) and Other (services, features, apps,
  programs, scripts on a running Windows and their mixes). A row has a twisty, a check box, the title, and
  on the right the count "on/total" of a group or the parameter of a rule.
- Check box states: on, off, mixed (a group with some rules on), blocked (a rule chosen on that waits for a
  rule it needs, with the tip naming it), linked (an imported policy whose values a built-in rule in effect
  writes: shown on, not changed here, `03-features.md` section 1).
- The rules of the selected group that are plain switches show a switch at the end of their rows, so a
  group is configured without visiting each rule; a setting turns this off.
- A policy two imports hold shows in the tree of each; the selection keeps the group it was selected in.
- The forms (Installation, Accounts, Languages) are the first items under the root of the answer file.
  The group Unknown options (the choices of a profile whose catalog is not loaded) is the last root; it
  exists only while there are any and a setting leaves it out. It lists their ids with on or off; its
  detail panel and that of each option explain that they stay in the profile and are left out of the
  build, and offer Load catalogs (`03-features.md` section 6).
- The tree is one stop of `Tab`. A click on a row gives it the focus; the arrows, `Home`, `End`,
  `Page Up` and `Page Down` move the selection (the row scrolls into view), `Left` and `Right` fold, unfold
  and go to the parent or the child, `Space` toggles, `Enter` opens a group.

### 6.2 Detail panel

The selection is shown in cards, from top to bottom:

1. The head: the title, the id with a copy button, chips (such as "on by default"), the on and off switch
   of a rule, its state (in effect, set by the built-in rule, blocked and what it needs); for a group the
   buttons Turn all on and Turn all off, the groups in it and its rules.
2. Parameters: the editor of the parameters of the rule (choices, numbers, texts, lists of one item or one
   `name=value` a line), with the default named under each. A text chosen from a list of Windows (the
   GeoID and the two-letter code of the user region) is typed freely with the list beside it, filtered by
   what is typed: a choice sets both parameters of the region at once, and the name of the region shows
   after the field.
3. This PC: the commands on this selection (check on this PC, read into the profile, apply to this PC,
   return to the Windows defaults, save an apply script, a return-to-defaults script, a registry file, a
   return-to-defaults registry file), each asking first where it writes.
4. In other catalogs: the same policy in the trees of other imports, and the policies of the same name in
   other imports, as links.
5. Description: a card that folds with its button or `Ctrl+D` (a setting keeps whether it is open). Inside,
   folding parts: What it does, Risk, What it writes (the registry values with their Windows default, each
   key with a button that opens the registry tab there), Dependencies and conflicts (the rules it needs,
   the ones that need it and its conflicts, as links), Versions, check and rollback, Reference (the page of
   the reference at its heading, opened in a Markdown tab, and the catalog tabs of the loaded imports at
   the rule). A setting chooses the parts open at first. The texts can be selected and copied.

### 6.3 Forms

Installation, Accounts and Languages are pages in the detail panel with labelled fields, the messages of
the check beside them, and a scroll when the page is taller than the panel. `Tab` walks the fields.

- Installation: the edition, the product key mode (generic, ask, a key), the time zone, the account mode,
  the computer name (random, fixed or a template, with the description of every placeholder and what the
  template gives with sample values), the workgroup, the disk mode.
- Accounts: name, display name, group, description and password of each account; From a users file
  (the accounts of a `.wwusers` file, with their passwords when its master password is given) and To a
  users file.
- Languages: the display language, the system and user locale (typed freely, with the languages of Windows
  in a list beside each, filtered by what is typed), the input languages in order (the first is the
  default), each with the layout of its choice, from the lists of Windows.

## 7. Diff view

A diff tab shows the differences as a list with columns (the item, its group, the value of each side, the
comment); the widths of the columns change by dragging, and the keys move through the list as in the tree.
The panel on the right shows the selected item: its two values, the way to it in either profile (the
profile opens from its file or preset when no tab has it, and the item is selected), Apply this
difference, then its comment of several lines, saved in the diff file, above the description of the rule.
The group of a rule leads to it in the first profile tab. The star marks the rule as a bookmark.

## 8. Catalog view

A catalog tab shows the policies of an import, or of a catalog or ADMX file opened without importing it,
as a tree with the same rows as a profile but without check boxes. The detail panel shows the policy with
its parameters, its registry values and its description, the rules it needs and conflicts with as links,
and Show in the profile tree, which loads an import that is not loaded, brings the first profile tab to the
front, opens the groups above the policy and selects it. Compare sets the catalog side by side with another
loaded import or an open catalog file in a Markdown page: the policies only in one of them and those whose
title, description, values, values when off, parameters or category differ. Edit opens the editor of the
catalog (section 18). Imports are also listed in Settings (section 10).

## 9. Bookmarks

- A bookmark is the id of an option (a rule, a group or a form) with a link to the profile it was made in
  and a comment, or a key or value of the registry. The star of the navigation row marks the selected
  option of a profile, a catalog tab or a diff; Bookmark in the registry tab marks the selected key or
  value. One option is one bookmark in every profile.
- Bookmarks live in `bookmarks.wwmarks` next to the executable, created at the first bookmark. Opening
  another bookmark file shows it in the bookmark tab, and the star writes there from then on.
- The bookmark tab is a list with columns (the option, its group, the profile, the comment) and the
  selected bookmark on the right: the option with its source catalog when it is not the built-in one, the
  comment of several lines, then the description of the option; for the registry, the rules that write
  the key. `Enter`, a double click or the button of a row opens the profile of the bookmark (loading it)
  at the option, or the registry tab at the key; `Delete` removes the bookmark after a question.

## 10. Settings tab

A page with a list of sections on the left and the section on the right:

- General: Language and theme (the language: follow Windows, English, the built-in languages and any
  folder found in `lang/`; the theme: follow Windows, Light, Dark and the other themes; Edit the theme,
  Open a theme file; the fonts of the theme); the window (open the tabs of the last session at the start,
  wrap lines to the width of the view, the width of pages: the view, at most so many pixels or characters;
  the renderer of the next start, Automatic or one of the renderers of the executable, with what the window
  draws with now); the lines of WinWeaver (show the description panel, the parts of the description open
  at first, open the guide at the next start, switches at the end of the rows of the selected group, hide
  the options whose catalog is not loaded).
- Policy templates: every catalog file of `imports/` with a check box: only the checked ones are read and
  loaded, the others show the name of their header and their size; Open, Rename, Remove, Export; the
  import commands of the menu Catalogs. When two loaded catalogs hold a policy, the templates of this
  Windows win.
- Files: the folders of the program, each with Open (made first when missing), and the recent files with
  Forget recent files.

## 11. MCP tab

- The MCP tab is the tab of the MCP server of W# (`wwmcp::ui`, docs/mcp.md of supakov/ww) with the
  cards of WinWeaver. It edits one configuration file (`02-documents.md` section 14), `mcp/default.wwmcp`
  at first, and saves it at every change; Open... and Save as... switch to another file (one of WinWeaver
  0.1.46 or earlier is written in the format of W# when it opens). Its fields: the port of HTTP; the mode
  (read: nothing changes; edit: what the program holds changes in memory; files: files are written too);
  the detailed log with Open the log (the log of today as a page); the transport of a start without the
  window; the token (copy the client configuration with it, renew it after a question); Copy the stdio
  configuration. **Tools**: the source WinWeaver with its switch, its options (Registry: off, reading,
  changing too; Allow reading the settings of this PC; Allow changing the bookmarks and the catalogs;
  the profile at the start) and its 36 tools by groups (profiles, rules, bookmarks, catalogs, registry,
  this PC), each group and each tool with its switch. **Call a tool**: any tool by its name with its
  arguments, as the program calls it, the answer below.
- Start and Stop run the HTTP server on 127.0.0.1 inside the window; its address and mode show in the
  status bar while it runs.
- The server has its own workspace of profiles, independent of the open tabs: the card Workspace of the
  server lists them, marks the changed ones and opens any of them in a tab for a look.
- The journal lists every call (time, client, call, arguments, result) with a search; the selected call
  shows in a panel on the right with its duration, its arguments, its answer and buttons to the places it
  names (rules, workspace profiles, catalog files, registry keys).

## 12. Keyboard navigation

- `Tab` and `Shift+Tab` move the focus between the widgets; a tree and a list are one stop each.
- The window: `Ctrl+N` new profile, `Ctrl+O` open, `Ctrl+S` save, `Ctrl+Shift+S` save as, `Ctrl+W` close
  the tab, `Ctrl+,` settings, `Ctrl+F` search, `Ctrl+Tab` and `Ctrl+Shift+Tab` next and previous tab,
  `Ctrl+Shift+PgUp` and `Ctrl+Shift+PgDn` move the tab.
- WinWeaver: `F1` guide, `F7` check, `F9` build, `Ctrl+B` bookmark, `Ctrl+D` description panel,
  `Alt+Left` and `Alt+Right` back and forward.
- Trees: section 6.1. Lists: the arrows, `Home`, `End` and the page keys move the selection, `Enter` or a
  double click opens, `Delete` removes where the tab allows it.
- A question over the window has its answer beside Cancel; `Esc` answers no.
- The window works with a screen reader as far as egui allows (AccessKit): every widget has a name.

## 13. Messages and busy states

- The message bar under the navigation row of a profile tab lists the results of the check and the
  warnings of the profile (unknown options, rules partly in effect); a click on a message selects its
  item, and the ids of rules and the registry paths in a message are links. The bar folds to one line or
  opens with a height the user drags.
- A question that needs a decision is a window over the tabs; every removal asks first (an import, a
  bookmark, closing a tab with changes, forgetting the recent files, renewing the MCP token, a key or a
  value, an account).
- A long operation (a read of this PC, an import of policy templates, a search of the registry, a native
  apply) runs in a thread of its own, so the window stays responsive; the status bar shows a spinner during
  a read of this PC.
- The status bar: the state of a profile (saved, modified, not saved yet), the catalog version with its
  count of rules, the MCP server while it runs, the last message, and Open the folder while the message of
  a saved or built file stays. Every new message of the status bar is written to the log.

- The work in the background shows in a panel over the lower right corner of the window: each work
  with its title, a detail, the time it has taken and Stop where it can stop; the panel folds to a
  spinner with the count (`App::jobs`, `ww::Job`). The spinner of the status bar stays while any runs.

## 14. Themes and sizes

- A theme is a file (`.wwtheme`, `02-documents.md` section 13): its name, a light or dark base, the colours
  it changes and its fonts (the family of the texts, their size from 10 to 36 points: by one up to 20,
  then 22, 24, 26, 28, 32 and 36 for large displays and poor sight, the chrome of the window growing with
  it; the family of code and values, the family of the icons). Light, Dark, Latte and Matrix are embedded; a file
  `themes/<id>.wwtheme` adds a theme or replaces the embedded one of its id. The theme follows Windows
  (Light or Dark) by default; the title bar takes the colours of the theme on Windows 11.
- The General section of the settings chooses the theme and its fonts; a change of a font is saved in the
  file of the theme. Edit the theme and Open a theme file open the editor of a theme as a tab: the name,
  the base, the fonts and every colour with "From the base"; while the tab is in front the window shows
  the theme as it is edited.
- The smallest window is 900 by 560 points. The window opens where it was closed, at the same size,
  maximized when it was; a place that does not fit the monitor is moved inside it and shrunk.

## 15. Registry tab

- The registry of this PC in the form of regedit: the tree of keys on the left, the values of the selected
  key on the right (name, type, data), an address field that takes `HKLM:\`, `HKLM\` and `Computer\...`
  paths. A value of a type that is only shown (REG_LINK, the resource lists) is not edited.
- New key, New value, Edit and Delete change the registry after a question where they remove; a change
  without the rights says that it needs WinWeaver as administrator.
- Find searches under the selected key in the names of keys, of values and in the data, depth first as
  regedit does, with a limit and a stop.
- Permissions opens a window over the tab: the owner and the access list of the key; inherited entries are
  shown, the entries of the key itself change (allow or deny, full control or read, where they apply), an
  account is added by its name; Apply asks first.
- The tab names the rules that write the selected key or value, as links.

## 16. Registry file tab

- A `.reg` file as an outline: each key with the comments right above it and the lines between its
  values, or comments alone; the lines of the selected key in a list.
- New key, New value, Edit and Delete change the file (a removal asks first and takes a key with its
  values, never its comments); Open in the registry opens the registry tab at the key. The rules that
  write a key are named.

## 17. Users file tab

- The accounts in a list (name, group, state, whether a password is set, profile folder) and the selected
  one in a form with the orders for an account that exists (`02-documents.md` section 11).
- Unlock asks for the master password; while unlocked, the password of the selected account can be shown
  and copied, and Lock hides the passwords again. Create on this PC and Apply passwords ask first and name
  the accounts that exist and will change.

## 18. Editor of a catalog

- Edit in the command bar of a catalog tab, or New catalog of the menu Catalogs (an empty import), opens
  the editor of the catalog file as a tab: the tree of its groups and policies on the left, the form of
  the selection on the right.
- The form of a policy edits it whole, as a rule of the built-in catalog: its title and description, its
  group, when it runs (a pass of the answer file, the script of the installation, the default user
  profile, the first sign-in, after OOBE), its level and whether it is on in a new profile; under Details
  what it does, the risk, the versions, how to check, the rollback, a note, the search words and the
  rules it needs and conflicts with; its parameters (a choice with its values, a number with its range, a
  text with its limit or a region to pick, a list); its actions of every kind, moved up and down (a
  registry value of any type, its removal, the values of a key from a list, a setting, an element of OOBE
  or a command of the answer file, lines of the script, the start of a service, a feature, capabilities
  and apps removed, a program), keys in the form of regedit; its Translations, every text in a language
  of the interface with the English one as the hint of an empty field. A policy that runs code says so.
- The form of a group edits its title, its description, the group or the root of the tree it sits in
  and its translations; the form of the file its name.
- The field Id with Rename gives a policy (with its Disabled rule), a group or the whole file a new id
  across the catalog: the rules that need or conflict with it, the groups and the translations follow.
  A new id of the file renames its file at the save and every id that starts with `admx.` and the old
  id (`admx.custom-1.mute` becomes `admx.office.mute`); the open profiles and the bookmarks follow the
  renamed policies at the save, and a profile that changed so says it.
- A key opens in the registry tab, the policy in the catalog tab and the profile.
- Apply checks the form into the file with the checks of the built-in catalog, Save (`Ctrl+S`) checks
  and writes the file and loads a loaded import again; a removal asks first.

## 19. Markdown pages and links

- A Markdown tab draws the guide, the licence, the pages of the reference and any `.md` file: headings,
  paragraphs, lists, quotes, tables, blocks of code with a copy button, links. The lines wrap to the width
  of the view, or the page scrolls sideways (a setting); a page is as wide as the setting Width of pages
  allows, and a table or a block of code wider than the view scrolls sideways.
- A link to an `#anchor` scrolls the page to its heading, a link to a `.md` page or a page of the program
  opens it in a tab, and any other link opens outside the program after a question.
- A rule named in a view is a link: in a profile it selects the rule and opens the tree down to it, in a
  catalog tab it selects the policy of its file, elsewhere it shows the rule in the first profile tab.
