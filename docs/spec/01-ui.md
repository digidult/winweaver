# 01. User interface

Draft 0.1, 14.10.2026. The mockups in `docs/design/` illustrate this file; the variant to build is chosen
by the customer, the behaviour below holds for every variant.

## 1. One window, documents as tabs

- The program has one window. Its content is a row of tabs; every tab is a document or a function.
- Document tabs: a profile (`.wwprofile`), a diff (`.wwdiff`), a catalog file (`.wwcatalog`), a bookmark
  file (`.wwmarks`), a Markdown page (`.md`). A document tab shows the file name, an unsaved mark (a dot
  before the name) and a close button; the tip shows the full path.
- Function tabs: MCP, Settings. A function tab exists at most once; opening it again activates it.
- A tab is closed with its close button, the middle mouse button or `Ctrl+W`; an unsaved document asks
  to save, discard or cancel. `Ctrl+Tab` and `Ctrl+Shift+Tab` cycle the tabs, `Ctrl+1` to `Ctrl+9` jump.
- A tab is moved by dragging it along the row (a line shows where it goes), with `Ctrl+Shift+PgUp` and
  `Ctrl+Shift+PgDn`, or with the menu of its right button (move left, move right, close). The tab in
  front stays in front, and the restored session keeps the order.
- The tab row scrolls when the tabs do not fit; the active tab is always visible. A "+" button after the
  last tab opens the New menu (a profile from a preset, an empty bookmark file).
- The window remembers the open tabs and the active one, and restores them at the next start; a file that
  disappeared is reported in a message bar, not in a dialog.
- A dropped file (drag and drop onto the window) opens in a new tab by its extension.

## 2. Toolbar

- A command bar in the style of Windows 11 apps: icons with short labels, grouped by separators, in one
  row under the tabs. The commands depend on the active tab:
  - profile: New, Open, Save, Check, Build, This PC (a split button: Read, Apply, Return to defaults,
    Save scripts), Compare;
  - diff: Open, Save, Apply to profile, Apply to this PC;
  - catalog: Open, Save, Show in tree, Hide;
  - bookmarks: Open, Save, Go to;
  - Markdown: Open, Reload, Open in browser;
  - MCP, Settings: no document commands.
- Every command has a shortcut shown in its tip. A narrow window hides the labels, then collapses the
  rightmost commands into an overflow menu.
- Under the toolbar sits the navigation row (section 3), then the content of the tab.

## 3. Breadcrumb navigation, history, bookmarks

- The navigation row holds: Back and Forward arrows, the breadcrumb of the current position, the bookmark
  star, the search (section 4).
- The breadcrumb shows the path of the selected item inside the active document: root, groups, the rule
  (for a profile or a diff), or the headings of a Markdown page. Every segment is a button that selects
  that item; the last segment is the current one. A segment with children opens a drop-down of its
  siblings on click of its chevron, so a neighbour is reachable without the tree.
- Back and Forward move through the history of selections of the active document (not across documents).
  `Alt+Left`, `Alt+Right`, the mouse side buttons. The history holds 100 positions per tab.
- The star adds the current position to the bookmark catalog (section 9) or, when it is already there,
  opens its entry to edit the comment. The star is filled when the position is bookmarked.

## 4. Search

- The search is an icon at the right end of the navigation row. A click or `Ctrl+F` expands it into a
  field across the free width of the row. While the field holds text, the icon becomes a clear button
  (an "x"); clearing it collapses the field back to the icon. `Esc` in the field clears and collapses.
- The search filters the tree or the page of the active document as the text is typed: in a profile or a
  diff the matching rules and their parents stay visible, the rest is hidden; the matches are highlighted;
  `Enter` and `Shift+Enter` move the selection to the next and the previous match; in a Markdown page the
  matches are highlighted and the page scrolls to the first one.
- Matching: case-insensitive, on the title, the id, the description, the search tags and the registry
  paths of a rule; several words match in any order; a word in quotes matches exactly.
- A drop-down under the field lists the last 20 searches (per program, saved in the settings); `Down`
  opens it, a click or `Enter` reuses an entry, `Delete` removes one.

## 5. Hamburger menu

The menu button (three lines) sits at the left end of the tab row. Its menu:

- New: a profile from a preset (Office, Strict, Laptop, Home), an empty profile, a bookmark file.
- Open..., Open recent (10 files), Save, Save as..., Save all, Close tab, Close all.
- Import: an answer file as a profile, ADMX templates of this Windows, ADMX templates of a folder, a
  catalog file. Export: the shown templates as a catalog file, the profile as scripts.
- Tools: MCP (opens the MCP tab), Compare two files...
- Documentation: the guide, the user documentation pages (each opens as a Markdown tab), the rule list.
- Settings (opens the Settings tab). About. Exit.

The menu opens with `Alt` or `F10` too and is fully keyboard driven (arrows, `Enter`, `Esc`, access keys).

## 6. Profile view

The profile tab is a split view: the tree on the left, the detail panel on the right, a draggable splitter.

### 6.1 Tree

- Rows: a twisty, a check box, the title, and on the right the count "on/total" for a group or a short
  state for a rule (a parameter summary such as "Block" or "mode 99").
- Check box states: on, off, mixed (a group with some rules on), disabled (a rule switched off by a
  dependency, drawn greyed with the tip naming the rule it waits for), linked (an imported policy that an
  enabled built-in rule already covers: drawn checked but not stored on).
- A group row can show the simple on/off controls of its direct child rules inline: when a group is
  selected or expanded, every child rule that is a plain switch without parameters shows a toggle at the
  right end of its row, so a group is configured without visiting each rule. A setting turns this off.
- Roots start expanded; the state of expansion is kept per document while the tab is open.
- `Space` toggles the selected row, `Left` and `Right` collapse and expand, `*` expands the subtree,
  `Home` and `End` jump, typing a letter jumps to the next title starting with it, `Ctrl+C` copies the id.
- The forms (Installation, Accounts, Languages) are the first items under the root of the answer file;
  the root of unknown rules (choices of a profile the loaded catalog does not have) is the last root and
  exists only while there are any.

### 6.2 Detail panel

From top to bottom:

1. Header: the title, the id in monospace, badges (mechanism: answer file, policy, other; the phase;
   the source of an imported policy; "on by default"), and the controls: the on/off switch of the rule,
   or for a group the buttons Turn all on, Turn all off, Reset to preset.
2. Parameters: the editor of the parameters of the rule (enums as drop-downs, strings, numbers, lists,
   check boxes), with the default shown as a hint and a Reset button per parameter.
3. Functions: for a rule or a group the This PC commands on this selection (Check, Read into the profile,
   Apply, Return to defaults, Save an apply script), each a button with a confirmation where it writes.
   For a group of plain switches a list of its rules with inline toggles.
4. Description: a panel that can be collapsed with a button in its header (and `Ctrl+D`); the setting
   remembers whether it is open. Inside, collapsible sections: Description, What it writes (registry
   values, answer file settings, script lines, as a table), Windows default, Dependencies and conflicts
   (links that select the rule), Reference (links to the documentation page and to the catalog of the
   rule, which open in another tab).

### 6.3 Forms

Installation, Accounts and Languages are pages in the detail panel with labelled fields in a two-column
grid, validation messages under the fields, and a scroll when the page is taller than the panel.
`Tab` walks the fields; the focused field scrolls into view.

## 7. Diff view

A diff tab shows the differences as a list with columns (the item, its group, the value of each side,
the comment); the widths of the columns change by dragging, and the keys move through the list as in the
tree. The panel on the right shows the selected item: its two values, "Show in" either profile (it opens
the profile from its file or preset when no tab has it, and selects the item), "Apply this difference",
then its comment of several lines, saved in the diff file, above the description of the rule. The
command bar: Open, Save, Save as, Apply (every difference to the base profile).

## 8. Catalog view

A catalog tab (an imported template tree) shows its policies as a tree with the same rows as a profile but
without check boxes; the detail panel shows the policy, its elements and its registry values, and a button
"Show in the profile tree" that adds the import to the shown trees and selects the rule. Catalogs are also
listed in Settings (section 10) where they are shown, hidden, renamed and removed.

## 9. Bookmarks

- A bookmark is the id of an option with a link to the profile it was made in and a comment. The star
  of the navigation row marks the selected option of a profile, a catalog tab or a diff; taking the
  star off a bookmark with a comment asks first. Bookmarks live in a bookmark file (`.wwmarks`); the
  default file `bookmarks.wwmarks` next to the executable is created at the first bookmark; another
  file can be opened and becomes the target of the star while its tab is active or, when no bookmark
  tab is open, the last used one.
- The bookmark tab is a list with columns (the option, its group, the profile, the comment) and the
  selected bookmark on the right: the option with its source catalog when it is not the built-in one,
  the comment of several lines above the description of the option. The mini button of a row, `Enter`
  or a double click opens the profile of the bookmark (loading it) at the option; `Delete` removes the
  bookmark (asking when it has a comment). The toolbar has Open.

## 10. Settings tab

A page with a list of sections on the left and the section on the right:

- General: language (follow Windows, English, the built-in languages and any folder found in `lang/`), theme
  (follow Windows, light, dark, the themes found in `themes/`), font size, open the guide at start,
  restore the tabs at start, inline toggles in the tree, the description panel open by default.
- Catalogs: the imports (bundled, this Windows, folders, catalog files) with show, hide, rename, remove,
  update in place, export; the trust order explained.
- Profiles: the folder of profiles, the recent files, the draft interval.
- MCP: the defaults of the MCP tab (section 11), the token.
- Advanced: logging level, the output folder, the limits of untrusted input, reset settings.

## 11. MCP tab

- The MCP tab holds the controls that used to live in a menu: transport (stdio instructions, HTTP on
  127.0.0.1 with a port), Start and Stop, the mode (read, edit, files), the option "Allow reading the
  settings of this PC", the token (show, copy, renew), the client configuration snippet to copy, and the
  monitor: the journal of requests with time, client, tool, result, and the connected clients.
- The server does not depend on the active document: it opens, edits and saves profiles through its own
  workspace (its own documents, listed in the tab, and openable as tabs for a look). The tab offers "Open
  in a tab" for every workspace document. Creating profiles is allowed in the modes edit and files, as the
  stdio server does without a window.
- The server state is shown in the status bar of the window while it runs.

## 12. Keyboard navigation

- Focus moves with `Tab` and `Shift+Tab` between the menu button, the tabs, the toolbar, the navigation
  row, the tree and the detail panel; `F6` cycles the panes. The focused element has a visible focus ring.
- Global: `Ctrl+N` new profile, `Ctrl+O` open, `Ctrl+S` save, `Ctrl+Shift+S` save as, `F7` check, `F9`
  build, `Ctrl+F` search, `Ctrl+B` bookmark, `Ctrl+D` description panel, `Ctrl+,` settings, `F1` guide,
  `Ctrl+W` close tab, `Ctrl+Tab` next tab, `Alt+Left`/`Alt+Right` back and forward, `Alt` or `F10` menu.
- Every dialog has a default button, `Esc` cancels, and the message bar (section 13) is reachable with
  `F8` and closes with `Esc`.
- The window works with a screen reader as far as egui allows (AccessKit): every widget has a name.

## 13. Messages and busy states

- Non-blocking messages (a file not found at restore, a draft recovered, the check result summary) appear
  in a message bar under the navigation row with a close button; errors that need a decision use a dialog.
- A long operation (an import, a read of this PC, a build) shows a progress bar in the status bar and a
  Cancel button where the operation can stop; the window stays responsive (the work runs in a thread).
- The status bar: the state of the active document (saved, modified, read-only), the catalog version, the
  MCP server state, the progress of a long operation.

## 14. Themes and sizes

- A theme is a file (`.wwtheme`): its name, a light or dark base, the colours it changes and its fonts
  (the family of the texts, their size from 10 to 20 points, the family of code and values). Light,
  Dark, Latte and Matrix are embedded (Latte and Matrix are the colours of the first version); a file
  `themes/<id>.wwtheme` adds a theme or replaces the embedded one of its id. The theme follows Windows
  (Light or Dark) by default; the colours of the title bar follow the theme on Windows 11.
- The General section of the settings chooses the theme and its fonts; a change of a font is saved in
  the file of the theme. "Edit the theme" and "Open a theme file" open the editor of a theme as a tab:
  the name, the base, the fonts and every colour with "From the base"; while the tab is in front the
  window shows the theme as it is edited. Its toolbar has Open, Save and Save as (another name is
  another theme).
- The window is usable from 1024x600 (the labels of the toolbar hide, the description panel collapses) to
  4K at 200 % scale (DPI aware per monitor).
