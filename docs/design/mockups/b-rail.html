What it does

Attack surface reduction rules of Microsoft Defender block the behaviours that malware uses most: Office spawning processes, scripts launching downloads, credential theft from LSASS. Each rule is a GUID with a mode: Block, Audit or Warn.

The Office preset turns 16 rules on; Strict adds the USB rule.
