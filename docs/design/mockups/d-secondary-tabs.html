WinWeaver guide

This page opens at the first start and from the menu or F1. It is a Markdown file in docs/, translated in lang/<code>/docs/.

First steps

  1. Open a preset from the menu: New ▸ Profile from a preset ▸ Office.
  2. Walk the tree; turn rules on and off; the description panel explains each one. Rules that depend on a rule you turned off are greyed.
  3. Check the profile (F7) and build the answer file (F9). The file lands in output/.

Build the answer file

Copy autounattend.xml to the root of the installation USB stick. Windows Setup reads it and installs without questions except those you left open in the Installation form. A link to a rule, such as defender.pua, selects it in the open profile; a link to a page opens another tab.
