Description

What it does

Turns off the advertising identifier, the tips, suggestions and the welcome experience that Windows shows to a new account; every rule is a per-user value written to the default profile, so accounts created after installation get it.

What it writes

Seven values under HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\ContentDeliveryManager and ...\AdvertisingInfo, written to the default user hive during specialize.
