# WinWeaver 0.34.0

The programs of WinWeaver are those of 0.33.0; wview reads the rest of a program of Windows and
saves its structure (wview 0.5.0, phase 5).

## What is new

- wview, the plugin of binary files:
  - Besides the headers, the sections, the exports and the imports: the resources (their types,
    names and languages, a level read when it opens), the exceptions of x64, the certificates, the
    relocations, the debug directory with the path of the PDB, TLS, the load configuration, the
    delay imports and the header of .NET with the streams of its metadata.
  - **Save the structure** writes the tree as a `.wwbin` file, next to the file by default: every
    field with its value, every range of raw bytes with its SHA-256, the file with its size and
    SHA-256, the description with its SHA-256, and none of the bytes of the file.
  - The language of the descriptions: a structure read when its node opens (`lazy`), a field or an
    item that ends at a multiple of bytes (`align`), an array of a length in bytes (`length`).
  - The bytes scroll exactly to the node selected.
  - The tests read the rest of `kernel32.dll` and the metadata of an assembly of .NET of the
    Windows they run on and save a `.wwbin`; the screenshot `v11-` shows the resources.
