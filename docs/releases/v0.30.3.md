# WinWeaver 0.30.3

The programs are those of 0.30.2; the repository gets the study of plugins for the programs on W#.

## What is new

- `docs/plugins.md`: how a program on W# can load plugins written in Rust from a folder, with the
  base code (std, egui, W#) in DLLs every such program shares; the ways Rust has, compared; what a
  prototype measured; the design and the phases of wview, a viewer of files with a plugin a format.
- `study/plugins`: the prototype, a workspace of its own. `wwrt.dll` holds W# and egui with the
  interface of the plugins and its loader, which checks that a plugin was built with it;
  `wview.exe` shows a file in a tab by the plugin of its format; `wv_text.dll` (27 KB) shows
  Markdown pages and text files, `wv_image.dll` (52 KB) every image format the decoders of the
  Windows it runs on take, with fit, zoom and the steps through the images of a folder.
