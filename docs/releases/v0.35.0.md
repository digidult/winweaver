# WinWeaver 0.35.0

The programs of WinWeaver are those of 0.34.0; wview compares a program of Windows with a
structure saved of it (wview 0.6.0, phase 6).

## What is new

- wview, the plugin of binary files:
  - **Compare with a structure** compares the file with a `.wwbin` saved of it, of another
    version of the file say: the tree of the changes, each with its value before and after, the
    nodes matched by their names and keys so that a new section moves no other, **Changed only**
    or **All nodes**, the offsets and the sizes of both sides, and **Show in the tree and bytes**.
  - A node of the comparison takes a comment and a bookmark; **Save the comparison** writes them
    with the names of both files to a `.wwbindiff`, and a `.wwbindiff` opens the comparison in a
    tab of its own.
  - A `.wwbin` opens alone as its tree or its page.
  - The eight languages and the guide say so; the tests compare a copy of `kernel32.dll` with one
    field changed and keep the notes of a comparison; the screenshot `v12-` shows one.
