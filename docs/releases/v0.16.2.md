# WinWeaver 0.16.2

The first release since 0.1.0-alpha.1. Nothing installs: unzip and run `winweaver.exe` on Windows 10 or
11. Changes of a computer belong in a virtual machine or on a test PC first.

The customer accepted build 0.11.0 in a virtual machine on 18.10.2026: the answer file, the four
stand-alone scripts (apply, undo, return to the defaults, audit), the native apply and its undo, the read
of This PC, the registry tab with its search and the editor of a catalog. What came after 0.11.0 waits
for the acceptance of its own scenario.

## New since 0.1.0-alpha.1

### The window

- The interface and the catalog in English, Ukrainian, Russian, German, Spanish, French, Indonesian,
  Italian and Turkish; Belarusian as a file next to the program, more languages as files.
- Themes with their colours and fonts (Light, Dark, Latte, Matrix, more as `.wwtheme` files) and their
  editor; the title bar takes the colours of the theme.
- Each tab has its own command bar and search; the tree and the lists work with the keyboard; tabs move
  by drag.
- Every rule, group, catalog and registry key a view names is a link: the rules a rule needs, the ones
  that need it and its conflicts, the rules named in the messages, the same policy in other catalogs.
- Two renderers, OpenGL and DirectX 12 (which also draws without a driver of the graphics card), tried
  in turn; `--renderer` chooses one.

### This PC

- Apply the selection to this PC, return it to the defaults of Windows and undo a change from its
  backup, natively and as administrator, with the default user profile for accounts made later.
- The script steps of the rules run natively too: .NET Framework 3.5 and drivers from the installation
  media, services, NetBIOS, the accounts of the profile, the copies of the answer file.
- Optional features and capabilities read through DISM, in the background; capabilities and apps
  removed natively.
- The apply and the return of the selection also saved as a registry file (`.reg`) for regedit.

### Policy templates

- ADMX templates imported from this Windows, a folder, a zip archive or a catalog file, the UTF-16
  templates of Chrome, Edge, Brave and Office included; catalog files (`.wwcatalog`) compared side by
  side and edited in their own tab; New catalog for your own policies.
- Options of catalogs that are not loaded stay in the profile; Load catalogs finds their imports.

### Registry

- The registry of this PC in a tab: keys, values of every type of regedit, edits, bookmarks, a search
  under a key, the rules that write a key, and the permissions of a key.
- Registry files open as their keys, values and comments, and save without losing a line.

### MCP server

- 34 tools for AI agents: profiles, the registry (off, read or write), bookmarks and catalogs.
- Its settings are configuration files (`mcp/<name>.wwmcp`, `winweaver --mcp FILE`); the MCP tab shows
  the details of every call; the log is JSON lines.
- `agents/` in the archive: instructions and skills for any agent and a container of the pi agent.

## Not yet

Nothing of the plan; what comes next comes from the use.
