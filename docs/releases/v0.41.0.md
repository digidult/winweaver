# WinWeaver 0.41.0

The programs of WinWeaver are those of 0.40.0; wview decodes images Windows has no decoder for
(wview 0.12.0).

## What is new

- wview:
  - Where the Windows it runs on has no decoder, the plugin of images decodes WebP, TGA, Netpbm
    (PBM, PGM, PPM, PAM), QOI, Radiance HDR and farbfeld itself, with the decoders of the crate
    `image`, all of Rust: no DLL comes with them. Such an image opens as any other (fit, zoom, the
    tiles, the steps through its folder); an animated WebP shows its first frame.
  - A QOI, farbfeld, Radiance HDR or Netpbm file of another extension opens by its first bytes.
  - The guide in nine languages names the formats.
- For the authors of plugins: wwrt re-exports the crate `image` (`wwrt::image`) with these
  decoders.
