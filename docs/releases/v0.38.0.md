# WinWeaver 0.38.0

The programs of WinWeaver and of wview are those of 0.37.0; the SDK of wview gets the crate
`wview-stable` for plugins of the stable interface in Rust of any toolchain (wview 0.9.0).

## What is new

- For the authors of plugins (the SDK, `stable/README.md`):
  - `stable/rust`, the crate `wview-stable` (edition 2021, Rust 1.77 or later, no dependency):
    a plugin of the stable interface (`wview.h`, version 1) in Rust without a line of C, built by
    any toolchain and loaded by every release of wview that knows the interface. A type implements
    `View` (`frame` from an `Input` to a `Frame` with a `Picture`, the `Control`s of the bar, the
    keys it takes, a `Cursor` and a line of the status bar; `control`), and `plugin!` exports
    `wv_plugin_get`.
  - The crate keeps the texts and the controls of a frame until the next call on the view, reads
    the input and writes the output by the sizes the host gives, and a panic of the plugin stops
    its view with the reason in the status bar instead of the whole program.
  - The folder copies out whole; the documentation of the crate holds a whole plugin, checked as a
    doctest.
- The tests: the functions of the table the crate makes called as a host calls them, and a plugin
  of the crate wrapped by the host of wview and drawn, so the two sides of `wview.h` are checked
  against each other.
