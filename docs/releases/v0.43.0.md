# WinWeaver 0.43.0

The programs of WinWeaver are those of 0.42.0; wview names where each plugin comes from and can
load only the plugins it trusts (wview 0.14.0).

## What is new

- wview:
  - Every plugin shows where it comes from: the SHA-256 of its DLL and its Authenticode
    signature with the name of its signer (or that it is not signed, or why Windows does not
    trust its signature), on the page of the plugins, in Settings, Plugins and in `--plugins`. The
    signature is checked without the network.
  - Settings, Plugins: **Load only the trusted plugins** loads only the plugins marked
    **Trusted**, known by the SHA-256 of their DLL (a new build of a plugin is a new plugin), and
    with **Trust a plugin whose signature Windows trusts** the ones whose signature Windows
    trusts too. A DLL not loaded shows its reason, its SHA-256 and its box Trusted. A change
    takes effect at the next start; settings of before load with every plugin, as until now.
  - The guide in nine languages tells it.
- For the authors of plugins: `wwrt::trust` and `Plugins::load_trusted`; wwrt re-exports `sha2`
  (`wwrt::sha2`), which the plugin of binary structures takes from there now.
