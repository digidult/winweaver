# WinWeaver 0.30.2

A fault found on 02.11.2026 by the test of the languages of Windows.

## Fixed

- On a Windows whose user has an input language without a locale id of its own (Russian
  (Ukraine), `ru-UA`, for one), Windows lends that language a transient id (2000) and the program
  took it for the id of the language: a profile with that language would have got the input
  profile `2000:00000419`, which means nothing on a new installation. The id is left out now, so the
  answer file gives the language the profile of its parent (`0419:00000419`) as on any other
  Windows, and the test `the_languages_and_layouts_of_this_windows_are_read` passes there too.
