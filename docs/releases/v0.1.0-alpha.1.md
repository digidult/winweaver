# WinWeaver 0.1.0-alpha.1

The first build of the successor of WinKickOff: the window with the profile editor, for a look at the
interface and the data model. Nothing installs; unzip and run `winweaver.exe` on Windows 10 or 11.
Run it in a virtual machine or on a test PC, not on a production one: the program is an alpha.

## What works

- The rule catalog of the predecessor (284 rules, 40 groups, English with Ukrainian and Russian texts
  of the rules) embedded in the executable; the presets Office, Strict, Laptop and Home.
- Profiles (`.wwprofile`): the tree with three-state group check boxes, dependencies resolved, the
  parameter editor, the collapsible description; the forms Installation, Accounts and Languages;
  Open, Save, Save as, recent files, a file dropped onto the window.
- Check (F7): the issues of the profile in a panel, a click selects the rule or the form.
- Build (F9): `output/autounattend.xml` with the embedded scripts, written next to the executable; the
  same passes, commands and rule blocks as the predecessor's build, not yet installed in a VM from this
  program.
- Compare with a file or a preset: the diff tab, the right side applied to the profile, `.wwdiff` files.
- This PC: the settings of this computer read through Windows into a new profile or into the selection,
  a check of the selection; apply, return-to-defaults and audit scripts saved for this or another PC;
  the report of an audit script opened as a profile.
- Opening answer files built by WinWeaver or WinKickOff, and WinKickOff profiles, as profiles.
- Bookmarks (`.wwmarks`): the Bookmark button in the navigation row, the Bookmarks tab with comments.
- The guide in English, Ukrainian and Russian at the first start and with F1; any `.md` file opens as
  a tab.
- The MCP server: `winweaver --mcp stdio` or `--mcp http`, or the MCP tab of the window; 19 tools, the
  modes read, edit and files.
- Settings (`settings.json` next to the executable): the language of the interface and the catalog
  (following Windows by default), the theme, the row switches, the tabs of the last session; drafts of
  unsaved profiles; a log.
- Keyboard: Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, F7, Ctrl+F, Alt+Left, Alt+Right, Ctrl+B, Ctrl+D,
  Ctrl+W, Ctrl+Tab, Ctrl+,, F1.

## Not yet

Applying and returning settings directly from the program (the scripts do it meanwhile), reading optional
features and capabilities natively, imported policy templates and catalog files, themes from files.
