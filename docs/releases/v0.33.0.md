# WinWeaver 0.33.0

The programs of WinWeaver are those of 0.32.0; wview, the viewer of files with plugins, opens
programs and libraries of Windows as the tree of their structure (wview 0.4.0, phase 4).

## What is new

- wview, the plugin of binary files (`wv_binary.dll`):
  - A file is read by a description of its format, a `.wwformat` file of strict JSON: its types,
    their fields, arrays, places in the file or at an address of its sections, conditions,
    switches, names of values and of bits, and small expressions over the fields read. The
    description of the Portable Executable is built in; more formats are descriptions in the
    folder `plugins\formats`, listed in Settings, Plugins with the ones that did not read.
  - Programs and libraries (`.exe`, `.dll`, `.sys` and the others) show their headers, their
    sections, their exports and their imports: on the left the tree, every field with its value,
    its offset and its size; on the right the bytes of the file with their ASCII, the bytes of the
    node selected marked, and a click on a byte selects the node that holds it.
  - **Text** shows the tree as a page with the search of the tab.
  - The file stays on the disk and is read in blocks; a node a short or damaged file does not
    hold whole is marked and says why.
  - Settings: the bytes in a row, the block of the file and the cache of its blocks; the eight
    languages and the guide say so.
  - The tests check the language on files of their own, read `kernel32.dll` of the Windows they
    run on, and the screenshots `v9-` and `v10-` show it in its tree and as a page.
- wwrt finds the folder of a plugin's DLL (the features of `windows` for the loader of modules).
