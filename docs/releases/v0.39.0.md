# WinWeaver 0.39.0

The programs of WinWeaver are those of 0.38.0; wview puts the icons of a program together and
opens a file by what it holds (wview 0.10.0).

## What is new

- wview:
  - A group of icons of the resources of a program (`GROUP_ICON`) shows with **Content** as one
    icon of every size, its sizes as the pages of the image, and **Save the node as a file** writes
    it as one ICO file. The images are the `ICON` entries the group names, in the language of the
    group where they have it.
  - A file of an extension no plugin names, or of none, opens by its first bytes: a text, an XML
    file, an image or a program under any name. A program of another extension opens with the
    description whose magic it has.
  - The guide in nine languages tells both.
- For the authors of plugins: `Plugins::for_file` finds the plugin of a file by its extension, else
  by the MIME type of its first bytes; a description names the form `image/x-group-icon;
  members=ICON` of the directory of a group.
