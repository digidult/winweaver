# WinWeaver 0.25.0

The customer's list of 24.10.2026: the window, the documents, the profile, the registry and Group
Policy files, drafts of every document, and the light edition wwlite in an archive of its own.

## What is new

- wwlite, the light edition, in its own archive `wwlite-<version>.zip`: the profile editor, the
  forms, the check and the build of `autounattend.xml`, the presets, catalogs from the folder
  `imports` and themes from the folder `themes`, a short guide as plain text, English and
  Ukrainian built in and German as files. `docs/wasm.md` studies an edition for the browser.
- Pages scroll with the arrows, Page Up and Down, Home and End, and keep their place and their
  selected text when another tab comes in front; the editor of wedit has Page Up and Down (with
  Shift they select) and takes the focus again when its tab comes back.
- The handle of a scroll bar is drawn in the colour of the text, so it shows on every theme.
- About is a window over the tabs. Closing a tab with changes asks: Save, Don't save, Cancel; the
  menu item that closed discarding the changes is gone.
- Every link goes through the window: a web link or a file of another kind is asked first, a `.md`
  or `.txt` file or a file without an extension opens in the program.
- Themes name a font of icons; with Segoe UI Emoji the icons of the command bar and the tabs are in
  colour.
- The documents describe the current state; the history of changes is in the release notes alone,
  and the earlier program is no longer named. Menu, Documentation opens the root page of the
  documentation built into the executable.
- Apply, return and audit scripts and registry files of the whole profile and of a diff, also from
  the command line (`--script`, `--reg`, `--only`, `--out`); no commands of This PC where nothing
  can be applied on a PC (the passes of the installation).
- The detail of a rule lists the rules of every catalog that write the same registry values, both
  ways; the parts of the description have colours of the theme.
- The registry tab: the values as a list with the keyboard; Rename (F2) of a value or a key.
- Registry files: the keys as a tree by default, the rules that write a key fold and scroll, Apply
  to this PC of a value, a key or the whole file after a question.
- Group Policy files (`.pol`): the files of this Windows and any file in a tab, a button beside a
  value Group Policy sets in the other tabs, a setting that opens them with a read of this PC.
- Drafts of registry files, diffs, the catalog editor, users files and the theme editor.

## Settled on purpose

- wwlite is the window of WinWeaver with these parts switched off at its start: its executable
  still carries their code, so it is built for Windows. An edition for other systems or for the
  browser would leave that code out; `docs/wasm.md` names what it takes.
- The users file in a draft keeps the passwords of its last save, encrypted; passwords typed since
  then come back only after a save.
- The handle of a scroll bar takes the colour of the text of the theme.
