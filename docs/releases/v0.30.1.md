# WinWeaver 0.30.1

The programs are those of 0.30.0; the repository gets the build of everything CI makes on a computer
of Windows.

## What is new

- `build-all.cmd` in the root of the repository: the release builds of WinWeaver, wedit and wwlite,
  wwlite for the browser, and the four archives of a release in `dist`, with the version in their
  names and their folders inside as a release has them. `check` runs the checks of a commit first,
  `screenshots` draws the window into `dist\screenshots`, `presentation` makes the slides of them,
  `all` does the three, and `noweb` leaves out the browser edition. The tools come from the PATH or
  from `WW_CARGO`, `WW_PYTHON` and `WW_WASM_BINDGEN`; wasm-bindgen of the version the build needs is
  downloaded once from its release on GitHub when it is missing, as CI does.
