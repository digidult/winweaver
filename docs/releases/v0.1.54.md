# WinWeaver 0.1.54

The ids of a catalog of the user are renamed in its editor, across the catalog.

## What changed

- **Rename a policy, a group or the whole catalog.** The forms of the editor of a catalog have the field
  Id with Rename: a policy gets a new id with its Disabled rule, and the rules that need or conflict
  with it, the groups and the translations follow; a group gets a new id with its policies and the
  groups in it. A new id of the catalog renames its file at the save and every id named after the old
  one, so a catalog made as `custom-1` with policies `admx.custom-1.<title>` becomes, say, `office`
  with `admx.office.<title>`, without a text editor.
- **The profiles follow.** At the save the open profiles take the new ids of the renamed policies
  (they are marked changed, to be saved too), the bookmarks follow, and the settings load the import
  under its new id. A profile file that is not open keeps the old ids, which show as unknown options.
