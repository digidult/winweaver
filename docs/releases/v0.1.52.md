# WinWeaver 0.1.52

The tree of a registry file shows a key deleted and written again as made anew.

## What changed

- **A key the file deletes and then writes again** showed in the tree of a registry file as its
  deletion alone, with no value: a list that replaces the values of its key is saved so (`[-key]`,
  then `[key]` with the list), and the tree took the first entry of the path. The tree now shows the
  last entry of a key, what the import leaves, and a key a line above deletes (the key itself or a
  key it is in) is marked ↻ as made anew, in the tree and in the list. Its head on the right says
  "Deleted first, then made anew" and why. The file and what it does are as before.
