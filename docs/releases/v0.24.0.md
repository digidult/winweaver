# WinWeaver 0.24.0

The second part of the refactoring of October 2026: the window of WinWeaver
becomes a framework, W# (`ww` in the code, WW in the documents), and a second program on it, the
text editor wedit, proves that the line between the window and the program is cut right. The
behaviour of WinWeaver does not change.

## W# (`crates/ww-base`, `crates/ww`)

- `ww-base`: the strict JSON documents, the paths inside the program folder and the clock, moved
  from the core as they were.
- `ww`: the shell of a window with tabs. A program implements `ww::App` (its documents, its acts,
  what it draws inside a tab, its command bar, its menus, its settings sections) and starts
  through `ww::run`; the shell owns the tabs, the settings, the themes with their editor, the
  session (drafts, the tabs of the last session, the log), the question over the window, and draws
  the tab row, the command bar, the navigation row, the message and status bars and the settings
  tab. The look, the painted tree and list, the Markdown viewer, the renderers and the
  translations are modules of `ww`. `docs/ww.md` describes it for its users.
- WinWeaver (`crates/winweaver-ui`) is the first program on it: `WinWeaver` implements
  `ww::App`, its acts of the window are `Act::Shell(ShellAct)`, its methods take the shell, and
  the chrome of 0.23.0 is gone from the crate.

## wedit (`crates/wedit`)

- A portable text editor in the look of WinWeaver: tabs of `.txt` and any text file in a
  monospace editor with its undo, Find with F3 and Shift+F3, the line and the column in the status
  bar, Save and Save as with the line ends the file came with, a draft two seconds after a change,
  the tabs of the last session; a `.md` file as a page with the search of its text and Edit as
  text; the menu, the command bar, the settings of the window alone; Light and Dark built in, more
  themes and languages as files; files dropped on the window or named on the command line.
- Its own archive `wedit-<version>.zip`: the exe, `README.md`, `lang/uk/ui.json` as the example
  of a language file.

## Also in 0.24.0 (the customer's list of 22.10.2026)

- The fields Display language, System locale and User locale of the form Languages take a tag typed
  freely and offer the languages of Windows in a list beside them, filtered by what is typed.
- Wrap lines to the width of the view (Settings, General) for the text of wedit and the pages of both
  programs; off, the view scrolls sideways. A page scrolls sideways for a table or a block of code
  wider than the view either way, and its code takes the colour Code on pages of the theme.
- The settings file is named after the executable (`winweaver.settings.json`, `wedit.settings.json`),
  so two copies with different names next to each other keep their own; a `settings.json` of 0.23.0
  is read and kept.
- Themes are extensible: a program adds its own colours (`ww::style::install_colors`), a theme file
  overrides them by name, and the theme editor lists them after the palette.
- Width of pages (Settings, General): a page of Markdown, its text, its blocks of code and its
  tables, is as wide as the view, or at most so many pixels or about so many characters (a narrower
  window makes it narrower); the text wraps at that width, a table fills it with its cells wrapped.
- The window opens where it was closed, at the same size, maximized when it was; a window that would
  not fit the monitor is moved inside it and shrunk.

## And the customer's list of 24.10.2026

- wwlite, the light edition, in its own archive `wwlite-<version>.zip`: the profile editor, the
  forms, the check and the build of `autounattend.xml`, the presets, catalogs from the folder
  `imports` and themes from the folder `themes`, a short guide as plain text, English and
  Ukrainian built in and German as files. `docs/wasm.md` studies an edition for the browser.
- Pages scroll with the arrows, Page Up and Down, Home and End, and keep their place and their
  selected text when another tab comes in front; the editor of wedit has Page Up and Down (with
  Shift they select) and takes the focus again when its tab comes back.
- The handle of a scroll bar is drawn in the colour of the text, so it shows on every theme.
- About is a window over the tabs. Closing a tab with changes asks: Save, Don't save, Cancel; the
  menu item that closed discarding the changes is gone.
- Every link goes through the window: a web link or a file of another kind is asked first, a `.md`
  or `.txt` file or a file without an extension opens in the program.
- Themes name a font of icons; with Segoe UI Emoji the icons of the command bar and the tabs are in
  colour.
- The documents describe the current state; the history of changes is in the release notes alone,
  and the earlier program is no longer named. Menu, Documentation opens the root page of the
  documentation built into the executable.
- Apply, return and audit scripts and registry files of the whole profile and of a diff, also from
  the command line (`--script`, `--reg`, `--only`, `--out`); no commands of This PC where nothing
  can be applied on a PC (the passes of the installation).
- The detail of a rule lists the rules of every catalog that write the same registry values, both
  ways; the parts of the description have colours of the theme.
- The registry tab: the values as a list with the keyboard; Rename (F2) of a value or a key.
- Registry files: the keys as a tree by default, the rules that write a key fold and scroll, Apply
  to this PC of a value, a key or the whole file after a question.
- Group Policy files (`.pol`): the files of this Windows and any file in a tab, a button beside a
  value Group Policy sets in the other tabs, a setting that opens them with a read of this PC.
- Drafts of registry files, diffs, the catalog editor, users files and the theme editor.

## Settled on purpose

- The drafts of WinWeaver keep their file format (`drafts/<key>.json` with the profile as JSON);
  the format name is `ww-draft`, and a draft of 0.23.0 (`winweaver-draft`) reads too.
- `settings.json` of 0.23.0 reads unchanged.
- The About text and the title of the window of WinWeaver keep their words; wedit has its own.
