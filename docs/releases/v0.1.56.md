# WinWeaver 0.1.56

An option of a profile goes into an open registry file, and every registry file names what its
rules do.

## What changed

- **To .reg** in the command bar of a profile copies the selected option, with its parameters in the
  profile, or the options of the selected group that are on, into a registry file open in a tab, after
  its own lines, or into a new one. Options of different groups of a profile go into one file without
  a file each.
- **Descriptions in the comments.** In such a copy and in every registry file the window saves from a
  profile, each rule has its id, its title and its description from the catalog in comments above its
  keys, in the language of the interface; `--reg` of the command line writes them in English.
