# WinWeaver 0.1.57 alpha

The first public alpha build of WinWeaver 0.1.57: the state of `main` on 21.11.2026, for trying it out.
It is not a final release; report what goes wrong in the issues of the repository.

## The archives

- `WinWeaver-0.1.57.zip`: the full program for Windows 10 and 11 (64-bit), portable: unpack it into a
  folder and start `winweaver.exe`; nothing is installed, the settings and the documents stay in that
  folder. The guide opens at the first start (F1).
- `wwlite-0.1.57.zip`: wwlite, the light edition: the profile, the check and the build of
  `autounattend.xml` alone.
- `wwlite-web-0.1.57.zip`, `winweaverweb-0.1.57.zip`: wwlite and WinWeaver for a browser, static pages
  for any web server (served over http, not opened from a disk).

## What it does

WinWeaver edits profiles of Windows installations and builds `autounattend.xml` from them, compares
profiles, reads the settings of a PC and applies them natively or through stand-alone scripts, imports
ADMX policy templates as catalogs and edits catalogs of its own, edits the registry, registry files,
Group Policy files and users files, and serves an MCP server for AI agents. The interface is in English,
Ukrainian, Russian, German, Spanish, French, Indonesian, Italian and Turkish.

The last changes are in the notes of the versions [0.1.53](https://github.com/digidult/winweaver/blob/main/docs/releases/v0.1.53.md) (catalogs of the user with every
feature of the built-in one), [0.1.54](https://github.com/digidult/winweaver/blob/main/docs/releases/v0.1.54.md) (the ids of a catalog renamed), [0.1.55](https://github.com/digidult/winweaver/blob/main/docs/releases/v0.1.55.md)
(the full search), [0.1.56](https://github.com/digidult/winweaver/blob/main/docs/releases/v0.1.56.md) (an option into an open registry file) and
[0.1.57](https://github.com/digidult/winweaver/blob/main/docs/releases/v0.1.57.md).

## Known limits of an alpha

- The executable is not signed: Windows SmartScreen may warn before the first start.
- Apply on this PC, the registry and the users change Windows: try them in a virtual machine first.
