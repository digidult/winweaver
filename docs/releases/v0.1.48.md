# WinWeaver 0.1.48

winweaverweb, WinWeaver in a browser (the list of 09.11.2026, the second, item 1).

## What changed

- **winweaverweb**: the window of WinWeaver for a browser, as `winweaverweb.html` (one file) and as
  a page for a web server (`winweaverweb-<version>.zip`). Every file of WinWeaver opens (a profile,
  an answer file, a diff, bookmarks, a catalog file, a users file, a Group Policy file, a registry
  file, a Markdown page) and saves as a download; the answer file, the stand-alone scripts and the
  registry files are built; the settings, the drafts and the bookmarks stay in the storage of the
  page.
- **An archive of policy templates** (a zip of ADMX files) opens as a catalog in a tab; Save gives
  its catalog file.
- **The folder of the page**: a page served over http reads the catalog files of `imports/`, the
  themes of `themes/` and the translations of `lang/` that `files.json` names (`manifest.py` writes
  it), before the window starts.
- Not in a browser: This PC, the registry of a PC, the native apply, the accounts of a PC and the
  MCP server (the features `pc` and `mcp` of the window, which WinWeaver has).
- The writes of WinWeaver go through the file layer of W# 0.1.48 (`ww_base::files`).
