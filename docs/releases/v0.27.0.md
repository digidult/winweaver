# WinWeaver 0.27.0

The customer's second list of 25.10.2026: the region of the default user profile chosen from a
list, the editors in the width they have, larger font sizes, every catalog file in the menu
Catalogs, wwlite for the browser, a presentation.

## What is new

- The region of the default user profile (`default-user.region`) is chosen from the regions
  Windows lists: the field of the GeoID or of the code with the list beside it, filtered as you
  type; a choice sets both. The check of a profile warns of a region Windows does not know; MCP
  `set_param` takes a code or a GeoID for them.
- Every editor and form keeps its fields in the width it has: the forms of the installation, the
  accounts and the languages, the catalog editor, the editors of a registry value, of a registry
  file and of a Group Policy file (their windows grow with the data, up to the window), users
  files, the theme editor.
- The size of the text goes up to 36 points (10 to 20 by one, then 22, 24, 26, 28, 32, 36), and
  the command bar, the tabs, the navigation row and the menus grow with it.
- The menu Catalogs lists every catalog file of the folder `imports`, the loaded ones with a
  mark and in the accent colour; a click on one not loaded loads it and opens its tab.
- wwlite runs in a browser: the archive `wwlite-web-<version>.zip` (a page, `wwlite.js` and the
  wasm module, served by any static web server) opens a profile or an answer file from the
  browser, edits, checks and builds it, and downloads the profile and `autounattend.xml`; the
  settings and the drafts live in the storage of the page, no log is written, and the input
  languages and keyboard layouts come from a list embedded for the browser alone
  (`data/resources/locales.json`, read once from a Windows 11; on Windows the lists still come
  from the system).
- A presentation for a prospective user, sixteen slides made of the screenshots of the build
  (`docs/presentation`), uploaded by CI as `presentation-<version>`.
